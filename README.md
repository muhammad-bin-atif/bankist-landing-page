🏦 Bankist Landing Page

A modern, minimalist, and interactive landing page built with Vanilla JavaScript, HTML5, and CSS3. 

This project demonstrates DOM manipulation, component building, smooth navigation, and browser APIs like IntersectionObserver.


📌 About the Project

Bankist Landing Page is a marketing website designed for a modern digital bank. It features smooth UI components, lazy-loaded visual elements, interactive tabs, a custom slider, and performance-optimized event handling.


✨ Features

- Smooth Scrolling: Smooth navigation transitions to page sections.
- Tabbed Operations Component: Interactive tab buttons switching content dynamically.
- Navigation Fade Effect: Hover animation blurring sibling links for focus.
- Sticky Navigation: Dynamic header using the Intersection Observer API.
- Reveal Sections: Smooth section scroll-reveal animations.
- Lazy-Loading Images: High-resolution images loaded on demand for performance.
- Custom Slider: Fully interactive image/testimonial slider with navigation buttons, keyboard support, and dynamic pagination dots.
- Modal Window: Interactive sign-up modal popup with ESC key and overlay click listeners.


🧠 JavaScript Concepts Used

1. DOM Manipulation & Event Delegation
- Event Delegation on navigation links and tab containers for optimal performance.
- Dynamic class switching for tabbed content and modals.
- Handling mouseover, mouseout, keydown, and click events.

2. Browser APIs & Performance Optimization
- Intersection Observer API: Used for efficient sticky navigation and scroll-reveal animations.
- Lazy Loading: Decreases initial page load time by swapping `data-src` to `src` as elements enter the viewport.
- Smooth Scroll API: Integrated `scrollIntoView()` for smooth navigation.


🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Intersection Observer API
